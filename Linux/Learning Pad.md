to Tape Archive many files to one file -> tar
    -x -> extract
    -c -> create
    -f -> the file, expects file immediately after this
    
to extract gunzip .gz files -> gzip
    can compress only one file

to extract bzip2 .bz2 files -> bzip2
        can compress only one file and is better but slower

to extract hex dump -> xxd
    -r -> reverse the hex dumping
